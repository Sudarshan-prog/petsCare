# 🎬 CareBridge — Demo Video Script
**Total Duration:** ~2 min 45 sec | Limit: Under 3 minutes  
**Format:** Screen recording of the app running on your phone/emulator + voiceover

---

## 🛠️ Before You Start Recording

- [ ] Run the app on your phone or Android emulator (`flutter run`)
- [ ] Use **Windows + G** (Xbox Game Bar) or **OBS Studio** to screen record
- [ ] Speak clearly, slowly — don't rush
- [ ] Record in a quiet room

---

## 🎙️ Recording Tips

| Tip | Detail |
|---|---|
| **Speed** | Speak at 70% of your normal speed — it sounds more confident on video |
| **Transitions** | Pause 1 second between scenes so edits are clean |
| **Mistakes** | If you make an error, just pause and restart that sentence — easy to cut |
| **Screen** | Keep your finger taps slow and deliberate so viewers can follow |
| **Duration** | Do a practice run with a timer — aim for 2:40 so you're safely under 3 min |

---

## 🖥️ How to Screen Record on Windows

```
Option A (Built-in):
  Press Win + G → click Record button (●)
  Stops when you press Win + G again → Stop

Option B (OBS Studio - Free):
  Download: https://obsproject.com
  Set source to: Display Capture
  Click "Start Recording"
  Output saved as .mp4 automatically
```
