# 🏗️ CareBridge: Strategic Resource Requirements

(technical)
1) Google Maps API Key
    - Enables location selection, pet-parent discovery, and proximity-based caretaker matching.
2) Razorpay API Key & Secret
    - Handles secure payments, UPI transactions, and automated marketplace commission collection.
3) Firebase Configuration (Cloud Services)
    - Connects the mobile app to the real-time database, cloud storage, and user authentication.
4) Cloud Messaging (FCM) Server Key
    - Triggers real-time push notifications for booking alerts, payment confirms, and chat messages.
5) Geocoding & Places API
    - Converts GPS coordinates into street addresses for precise pet-care location tracking.

(non-technical)
1) Google Cloud Billing Account
    - High-volume data processing for thousands of concurrent pet-care sessions without service gaps.
2) Razorpay Verified Business Account
    - Legal authorization to handle Indian transactions and automate profit/payout splits.
3) Google Play Console Developer Account
    - Official gateway to publish the CareBridge app to the 1.4 Billion+ Android user market.
4) Apple Developer Program Membership
    - Access to the premium iOS market to serve high-income pet parents on iPhone devices.
5) Corporate Web Domain (e.g., carebridge.in)
    - Legal hosting for privacy policies, support dashboards, and professional company communication.
