The Solution
CareBridge — One app. Complete trust.

A trust-first platform that verifies caretakers before they can accept bookings, matches owners to the nearest professionals via GPS, and provides AI-powered wellness guidance.

🛡️
Tiered Verification

3-level trust badges: Verified → Trusted → Pro, earned through real-world checks.

📍
GPS Proximity

Real-time map showing nearest verified caretakers using Haversine distance.

🚨
Emergency SOS

Instant filter for on-call caretakers — booking in under 2 minutes.

🤖
AI Care Assistant

RAG-based chatbot: local knowledge base + Gemini API fallback.

🐶
Adoption Hub

Browse pets from partner NGOs and shelters — all in one place.

💳
Secure Payments

Razorpay manual-capture — money held safely until service is confirmed.

Core Feature
Tiered Trust Verification System

CareBridge's defining differentiator. Caretakers earn trust tiers through verifiable, real-world milestones — displayed as prominent badges visible before every booking.

🟢
Verified
Government ID scanned & confirmed
isIdVerified: true
🔵
Trusted
Verified + Background check passed
isBackgroundChecked: true
⭐
Pro
Trusted + NGO/Partner endorsement
isPartnerEndorsed: true

💡 Trust Modal: Before booking, owners see a pop-up checklist showing the caretaker's exact verification status — ID check, background check, and which NGO endorsed them. Full transparency, zero guesswork.

Payments
Trust-first payment flow via Razorpay

Funds are authorized (not captured) at booking time. Money moves only when the caretaker actively accepts — protecting both parties from fraud and cancellations.
